# dev-notes

这个文件夹是用来存放开发过程中遇到的技术困难，以及记录技术决策的前因后果。

## 文件内容及规范

文件格式一律为 markdown 格式。

### 文件名规范

`[主题]-[日期]`。其中日期时间格式为 `YYYYMMDD-hhmm`。

- **模块类文档**：主题取模块名，例如 `connection-20261002-0548.md`（连接层）；
- **非模块类文档**：主题取文档自身的性质或方向，用小写英文短语，例如
  `outlook-concurrency-20261002-2322.md`（跨线程与并发模型的**设计展望**）。
  设计展望、跨模块决策、调研记录一律走这一类，不要硬塞进某个模块名下。
